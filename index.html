APA YANG DIPELAJARI?

Materi workshop

Pilih topik untuk membaca ringkasannya.

01

Prompt Engineering

Cara menyusun instruksi yang jelas agar AI memberikan hasil yang tepat dan sesuai kebutuhan.

Prompt adalah instruksi atau masukan yang diberikan kepada model AI. Prompt yang baik memiliki peran (role), tugas (task), konteks (context), dan format output (format). Konteks yang jelas membantu AI memahami kebutuhan pengguna.
02

Pengenalan Git & GitHub

Mengenal fungsi Git sebagai version control dan GitHub sebagai platform kolaborasi online.

Git mencatat perubahan pada file atau proyek. GitHub merupakan platform berbasis web untuk menyimpan repository Git secara online dan mendukung kolaborasi.
03

Git Workflow

Memahami alur perubahan file dari working directory ke staging area, lalu commit.

Working directory adalah tempat kita mengerjakan file. Staging area menampung perubahan yang akan dimasukkan ke commit. Git directory menyimpan database dan informasi yang dibutuhkan Git untuk mengelola proyek.
04

Setup Git & VS Code

Menyiapkan Git, identitas pengguna, dan Visual Studio Code sebelum mulai bekerja.

Setelah Git diinstal, periksa dengan git --version. Atur nama dan email menggunakan git config --global user.name serta git config --global user.email. VS Code juga dapat diperiksa melalui terminal dengan code --version.
05

Repository & SSH Key

Membuat atau menyalin repository dan mengenal autentikasi SSH ke GitHub.

Repository dapat dimulai dengan git init atau disalin dari GitHub menggunakan git clone. Materi juga memperkenalkan pembuatan SSH key dan penambahan public key ke pengaturan GitHub untuk autentikasi.
06

Commit & Push

Menyimpan perubahan dan mengirimkannya ke repository GitHub.

Perubahan dipilih dengan git add, disimpan sebagai riwayat menggunakan git commit, lalu dikirim ke repository online menggunakan git push. git pull mengambil perubahan dari remote dan menggabungkannya ke branch saat ini.

RANGKUMAN

Perintah Git dasar

Beberapa perintah yang dikenalkan selama workshop:

git initMemulai repository Git baru.
git add .Menambahkan perubahan file ke staging area.
git commit -m "pesan"Menyimpan perubahan ke riwayat repository.
git remote add origin URLMenghubungkan repository lokal dengan repository remote.
git push origin mainMengirim commit ke branch main di remote.
git pull origin mainMengambil dan menggabungkan perubahan dari remote.
git clone URLMenyalin repository dari sumber remote.
