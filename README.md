Materi Workshop
1. Prompt Engineering
Prompt Engineering adalah cara memberikan instruksi kepada AI agar hasilnya sesuai dengan kebutuhan. Dalam membuat prompt, ada empat hal yang perlu diperhatikan, yaitu Role (peran AI), Task (tugas yang diberikan), Context (informasi pendukung), dan Format (bentuk jawaban yang diinginkan). Instruksi yang jelas akan membantu AI memberikan hasil yang lebih tepat.

2. Pengenalan Git dan GitHub
Git merupakan version control system yang digunakan untuk mencatat dan mengelola perubahan pada file atau project. Sementara itu, GitHub adalah platform online untuk menyimpan repository Git dan memudahkan kolaborasi. Keduanya saling berhubungan, tetapi memiliki fungsi yang berbeda.

3. Git Workflow
Dalam Git terdapat tiga bagian utama, yaitu Working Directory sebagai tempat mengubah file, Staging Area sebagai tempat menyiapkan perubahan, dan Git Directory sebagai tempat menyimpan riwayat perubahan. Alurnya dimulai dari mengubah file, memasukkannya ke staging area, lalu menyimpannya menggunakan commit.

4. Perintah Dasar Git
Beberapa perintah yang dipelajari selama workshop antara lain "git init" untuk membuat repository, "git add ." untuk menyiapkan perubahan, "git commit" untuk menyimpan perubahan, "git push" untuk mengirim project ke GitHub, "git pull" untuk mengambil perubahan terbaru, dan "git clone" untuk menyalin repository.

5. Pengaturan Git dan SSH Key
Sebelum menggunakan Git, kita perlu melakukan instalasi dan mengatur username serta email. Selain itu, SSH Key juga dapat digunakan untuk menghubungkan komputer dengan GitHub agar proses autentikasi dapat dilakukan dengan lebih mudah.
